# TSan suppressions — dliio.  See doc/FINDINGS_2026-07-02_tsan_races.md.
#
# These are FALSE POSITIVES, not real races. Each suppressed member is touched by
# a SINGLE MutuallyExclusive callback group and is therefore never genuinely
# accessed concurrently. TSan reports them only because rclcpp/rcl are not
# compiled with TSan (only dliio is), so the executor's callback-group
# happens-before edge between successive callbacks that land on different worker
# threads is invisible to TSan.
#
# Genuine cross-group shared state IS correctly locked and is deliberately NOT
# suppressed here, so a real regression there still fires:
#   - state / imu_stamp / degen_cov_extra_   -> geo.mtx
#   - imu_rates                              -> mtx_imu
#
# Scope is kept narrow (single-purpose functions only). callbackImu is NOT
# suppressed wholesale — its calibration-phase accumulator races
# (calib_gyro_avg_/accel_avg_/num_samples_, first ~3 s, single-group, benign) are
# left visible on purpose so a future genuine race in callbackImu is not masked.
